# Client iOS

Cible : iPhone/iPad, SwiftUI.

Le client consomme uniquement le contrat schemas/daily_picks.schema.json. Aucune logique de prédiction ni aucun secret du pipeline ne doit être embarqué dans l'application.

Écrans prévus : Picks du jour, détail d'un pick, historique, détail d'un match, paramètres/notifications, méthodologie et mentions légales.
